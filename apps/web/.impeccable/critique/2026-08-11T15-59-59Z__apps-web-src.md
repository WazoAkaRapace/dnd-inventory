## Remaining Priority Issues

### [P1] BottomSheet has no focus trap (accessibility regression vs. Modal)
Modal traps focus, restores previous focus, blocks body scroll. BottomSheet only handles Escape. Keyboard/screen-reader users can Tab out behind the scrim.
**Fix:** Extract useFocusTrap hook, apply in both.
→ `$impeccable harden`

### [P1] No undo on delete; no undo on coin auto-save
Confirm gate prevents accidents but not regret. "Retirer" is one tap away mid-combat; coins commit on blur.
**Fix:** 5s soft-delete with "Annuler — X restauré" toast; one-step undo for coins.
→ `$impeccable harden`

### [P2] Tour vanishes after first add; doesn't explain anything
Gated on entries.length === 0, so it disappears when most needed. References mobile-only copy on desktop.
**Fix:** 3-step coachmark (catalog → encumbrance → expand-for-details), gated on tour-seen only.
→ `$impeccable onboard`

### [P2] Large inventories unmanageable
Category collapse state is in-memory (lost on refresh), no jump-to-category, no collapse-all. 50+ items = wall of cards.
**Fix:** Hoist collapse state to parent + localStorage, add chip nav, add "Tout replier."
→ `$impeccable distill`

### [P3] Feedback dialect inconsistent across pages
Only CharacterInventoryPage uses toasts. PartiesPage/GmDashboardPage/PartyPage still use inline error banners.
**Fix:** Hoist ToastProvider to App.tsx, consume everywhere.
→ `$impeccable polish`

## Minor Observations

- pulse-warn opacity flicker is close to WCAG threshold (slower than 3/sec, technically fine, but a steady red ring might be calmer)
- Nav ⚔/🏠 glyphs not marked aria-hidden — screen reader announces "crossed swords Inventaire D&D"
- fetchCatalog swallows errors silently — catalog API down shows "Aucun objet trouvé" (misleading)
- Coin summary "120 PO 45 PC" reads slightly cryptic
- refreshInventory refetches whole inventory per mutation — will jitter on slow networks

## Questions to Consider

1. Why is encumbrance only explained at party creation? The most consequential status gets a one-line aria-valuetext. Should the encumbrance card explain the tier on first hover/tap?
2. Is search-only right for D&D? Players browse "weapons," not search "longsword." A category-landing catalog would be more in-world.
3. Why does the tour hide once items exist? It should fire on the first "overburdened" state change, not on empty.
4. If a DM manages 6 PCs, why is there no party-inventory-at-a-glance view?
